# PixelRun Adventures

A browser-based pixel platformer built with HTML, CSS and JavaScript.

## Features

- Keyboard controls
- Mobile touch controls
- Coin collection
- Enemy stomping
- Multiple worlds
- Map shop
- Score system
- Lives and timer

## Controls

← → Move
SPACE / ↑ Jump
P Pause

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API
